# 💚 Mental Health Companion Agent

An AI-powered mental health journaling companion with persistent memory,
28-emotion detection, RAG-powered coping toolkit, and clinical session notes.

## Features

- 🧠 GoEmotions 28-emotion BERT detection
- 💾 RAG memory with ChromaDB
- 🚨 Crisis detection with India helplines
- 🛠️ CBT coping toolkit (54 techniques)
- 📋 Clinical PDF session notes
- 📊 Mood analytics dashboard
- 🌍 8 Indian language support
- 🔐 User authentication

## Tech Stack

Python · LLaMA 3.3 · Groq · ChromaDB · SQLite · NLTK · Streamlit · Plotly
